ใส่ไฟล์ MF (+ CNTRS) แล้วกด Process

แยกตาม DELIVERY จาก CNTRS (Port Of Delivery และ SHED NUMBER): 0332 = THLKR · 0110 = THBMT · 0302 = THSCT · 0122 = THBKK · อื่น ๆ = THLCH (หรือ THBKK ถ้าเรือลงที่ BANGKOK) · MYANMAR / LAOS / MALAYSIA / CHINA / CAMBODIA = CARGO MOVEMENT (7-TRANSIT) ตามรหัสประเทศ · TRANSHIPMENT = CARGO MOVEMENT TRANSHIPMENT · EMPTY = ตู้เปล่า HEUNG A (4=MTY) · แสดงเฉพาะหัวข้อที่มีข้อมูล
ตู้ SOC = ตู้เจ้าของอื่นที่อยู่ใน CNTRS แต่ไม่มีใน MF แยกตามเจ้าของ (CONSIGNEE) และขนาด แล้วรวมใน GRAND TOTAL · ขนาดตู้จาก CNTRS (ถ้าไม่มี ใช้รหัส 22G0 = 20' · 45G0 = 40')
MF เป็น Excel → ได้ MF-LCH.pdf / MF-LKR.pdf / … แยกตาม DELIVERY มีหน้า SUMMARY เป็นใบปะหน้า (ตัวแดงตาม shed ทุกหน้า) · CNTRS เป็น Excel → ได้ CNTRS.pdf แยกตาม DELIVERY จาก SHED NUMBER (0332 = THLKR /GATE n …) และแยกตู้ SOC
ชื่อ / ตำแหน่ง / เบอร์โทร จำไว้ในเบราว์เซอร์นี้ (แต่ละคนแก้ของตัวเองได้) · ตรวจกฎ (MF / CNTRS ที่เป็น Excel): SHED (DG = 2826 · LAOS ลง BKK = 0124 · USED ENGINE ลง BKK = 0126 · SHED ใน MF ตรงกับ CNTRS) · ประเทศปลายทาง · CARGO MOVEMENT (TRANSHIPMENT = 3 · TRANSIT = 7) · TAX ID = NOTIFY · DG และขนาดตู้ MF ตรงกับ CNTRS · ตู้ DG ใน CNTRS อยู่ 2826 — ถ้าเจอจะขึ้นกล่องแจ้งเตือนใต้ตาราง (เอกสารยังทำให้ตามปกติ)
